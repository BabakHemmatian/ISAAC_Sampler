Direct Download

Programmatic, scriptable access to the curated ISAAC (Illinois Social Attitudes Aggregate Corpus) Reddit data files. If you just want to sample and filter without writing code, use the web app instead. This page is for pulling whole monthly files directly into your own scripts and pipelines.

URL scheme

Every file is a plain GET over HTTPS. No authentication, no query parameters:

https://g-05a4b6.2d513.8443.data.globus.org/<category>/<prefix><YYYY-MM>.csv
  • <category> — one of abilityageracesexualityskin_toneweight
  • <YYYY-MM> — month, e.g. 2015-03 (zero-padded).
  • <prefix> — ALL_ for sexuality (combined comments + submissions); RC_ (Reddit Comments only) for the other categories until their combined versions are published.

Example: https://g-05a4b6.2d513.8443.data.globus.org/ability/RC_2010-01.csv

Every month is also available as Apache Parquet at the same path with a .parquet extension (e.g. https://g-05a4b6.2d513.8443.data.globus.org/age/RC_2015-03.parquet). Parquet is recommended for scripting — it supports column selection and partial reads, so you transfer far less than the full file.

Every category has both CSV and Parquet for all 204 months (2007-01 through 2023-12). The manifest is always the authoritative list of what exists.

Individual files range from tens of KB to several hundred MB — check size_bytes in the manifest before bulk-pulling. Downloads support HTTP Range requests, so large transfers can be resumed.

File schema (current columns)

id, parent id, text, author, time, subreddit, score, matched_patterns

See the variable list for full column definitions. These files are the current pre-labeling release; the forthcoming labeled release will add per-post fields for moralization, sentiment (Stanza/VADER/TextBlob), generalization, emotion, and estimated user location.

Machine-readable index

Rather than hard-coding filenames, enumerate what's available from the manifest:

  • manifest.json — array of {category, year, month, format, filename, rel_path, size_bytes, num_rows, url}
  • files.csv — the same data as a flat CSV

Python loader (isaac-data)

The easiest way to use the corpus from Python. It reads the manifest above as a catalog and, for Parquet, transfers only the columns you ask for (HTTP range reads). Source on the project repository.

# install (PyPI once published):
pip install isaac-data
# or from the repo:
pip install "git+https://github.com/BabakHemmatian/Illinois_Social_Attitudes.git#subdirectory=isaac-data-loader"
import isaac_data as isaac

isaac.files("race", "2018-01", "2018-12")          # what's available (DataFrame)

# load one month, only two columns (transfers just those columns):
df = isaac.load("race", "2018-03", "2018-03", columns=["text", "score"])

# stratified sample: 1000 rows total across the 12 months (reproducible):
sample = isaac.load("age", "2015-01", "2015-12", columns=["text"], n=1000, seed=0)

# bulk download for offline use (resumable, cached):
isaac.download("weight", "2020-01", "2020-12", dest="./weight2020")

CLI: isaac-data ls -c race -s 2018-01 -e 2018-12 · isaac-data download -c age -s 2015-01 -e 2015-12 -d ./age

Examples

Prefer the loader above for Python. These raw HTTP examples work in any language.

Download one file

# curl — works on macOS, Linux, and Windows 10+ (-O keeps the remote name, -L follows redirects)
curl -LO https://g-05a4b6.2d513.8443.data.globus.org/ability/RC_2010-01.csv

# resume an interrupted download
curl -C - -LO https://g-05a4b6.2d513.8443.data.globus.org/ability/RC_2010-01.csv

# GNU wget — Linux / WSL / Git Bash only (not preinstalled on macOS; "wget" in Windows
# PowerShell is an alias for a different command and will not behave like this)
wget https://g-05a4b6.2d513.8443.data.globus.org/ability/RC_2010-01.csv

Load straight into pandas (no local copy)

import pandas as pd

url = "https://g-05a4b6.2d513.8443.data.globus.org/ability/RC_2010-01.csv"
df = pd.read_csv(url)
print(df.shape, list(df.columns))

# Parquet (available for every category and month):
df = pd.read_parquet("https://g-05a4b6.2d513.8443.data.globus.org/sexuality/ALL_2010-01.parquet")

Download many files (a URL list)

Save the file URLs you want to isaac_urls.txt, one per line — the Sampler produces this list for a no-code selection, or build it from the manifest or the isaac-data loader (isaac.files(...).url.tolist()). Then fetch them all:

# curl + xargs — no install on macOS / Linux / WSL / Git Bash; 8 downloads in parallel
xargs -P8 -n1 curl -O < isaac_urls.txt

# aria2c — fastest: parallel + automatic resume (install via brew / apt / choco)
aria2c -j8 -i isaac_urls.txt

# Windows PowerShell (native) — note: PowerShell's "wget" is NOT GNU wget
Get-Content isaac_urls.txt | ForEach-Object { Invoke-WebRequest $_ -OutFile (Split-Path $_ -Leaf) }

Every option pulls straight from the Globus storage endpoint, in parallel where supported — nothing routes through this website.

Select files from the manifest

import requests

manifest = requests.get(
    "https://isaac.psychology.illinois.edu/direct-download/manifest.json"
).json()

# e.g. all CSVs for 'race' in 2018-2020
wanted = [f for f in manifest
          if f["category"] == "race"
          and f["format"] == "csv"
          and 2018 <= f["year"] <= 2020]

for f in wanted:
    print(f["url"], f["size_bytes"])

Query with SQL (DuckDB)

DuckDB can query the Parquet directly over HTTPS, reading only the columns and row groups your query needs (range requests) — so a selective query transfers far less than the file size. The query runs on your machine; nothing runs on our server.

Want to try SQL without installing anything? Use the in-browser SQL playground — the same engine (DuckDB-Wasm), running entirely in your browser tab.

import duckdb

# One month — aggregate without downloading the file:
duckdb.sql("""
  SELECT subreddit, count(*) AS n, avg(score) AS avg_score
  FROM read_parquet('https://g-05a4b6.2d513.8443.data.globus.org/race/RC_2018-03.parquet')
  GROUP BY subreddit ORDER BY n DESC LIMIT 10
""").show()

For multiple months, pass an explicit list of URLs. (HTTP has no directory listing, so wildcard globs like RC_2018-*.parquet do not work — build the list from the manifest or the isaac-data loader.)

import duckdb

base = "https://g-05a4b6.2d513.8443.data.globus.org/race"
urls = [f"{base}/RC_2018-{m:02d}.parquet" for m in range(1, 13)]

duckdb.sql("SELECT count(*) AS n FROM read_parquet($urls) WHERE score > 100",
           params={"urls": urls}).show()

# or get URLs straight from the loader:
# import isaac_data as isaac
# urls = isaac.files("race", "2018-01", "2018-12").url.tolist()
# Command line (single file):
duckdb -c "SELECT author, score FROM \
  read_parquet('https://g-05a4b6.2d513.8443.data.globus.org/age/RC_2015-03.parquet') \
  WHERE score > 500 LIMIT 20"

DuckDB auto-loads the httpfs extension on first use of an https:// path; if an older build doesn't, run INSTALL httpfs; LOAD httpfs; first. Keep an eye on LIMIT/filters for very large multi-month scans.

Notes & data use

Do not share this page, these URLs, or the data with others. Access to ISAAC is conditioned on accepting the Data Use Agreement, which prohibits redistribution. Anyone else who wants the data must go to the ISAAC website and accept the Agreement first — please direct them there rather than passing along files or download instructions.
These files are served read-only. Only GET and HEAD are accepted — the data cannot be modified through this endpoint.
  • Your use of these files is governed by the ISAAC Data Use Agreement — non-commercial research only, no re-identification attempts, no redistribution, and no training of generative models on third-party cloud services.
  • Please download considerately — pull the months you need rather than mirroring the whole ~668 GB corpus in tight parallel loops.
  • The data and categories match the corpus served by the ISAAC web app.
  • If you use ISAAC in published work, please cite the project and acknowledge the dataset — see the main ISAAC repository, whose README includes citation details.
