SQL Query Playground

Query the ISAAC corpus with SQL — running entirely in your browser via DuckDB-Wasm. Your query reads the Parquet files over HTTPS directly from the public NCSA Taiga Globus collection, fetching only the columns and row segments it needs. No query or corpus data passes through our servers — the database runs in this tab. For filtered or aggregated extractions this is ideal; for heavy pulls prefer the Python package or direct downloads.

Files are one Parquet per social group per month, addressed as https://g-05a4b6.2d513.8443.data.globus.org/<group>/<prefix><YYYY-MM>.parquet — groups ability, age, race, sexuality, skin_tone, weight; the prefix is ALL_ for age and sexuality (combined comments + submissions) and RC_ (comments only) for the other groups; months 2007-01 through 2023-12. A single query can span months and groups by listing several files inside read_parquet([...]). For the columns you can SELECT and filter on, see the variable list. Full docs and the file manifest are on the Direct Download page.

Because computation happens in this browser tab, the playground is suited to aggregation and moderate result sets. Results display up to 10,000 rows; Export CSV writes up to 100,000 rows. Queries that scan the full text column across many months will prompt a warning first. For larger extractions, use the Python package or direct downloads.

File-list helper

Pick one or more social groups and a month range; this builds the read_parquet([...]) file list — including a social_group identifier column so combined groups stay distinguishable — and drops a ready-to-run query into the editor below.
